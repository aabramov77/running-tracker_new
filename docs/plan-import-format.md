# Формат файла плана тренировок

Приложение умеет загружать план тренировок из файла на вкладке «План»
(кнопка **⤒ Загрузить**) и выгружать текущий план в тех же форматах
(**⤓ CSV**, **⤓ JSON**). Поддерживаются два формата: **CSV** и **JSON**.

Примеры лежат рядом: [`samples/plan-example.csv`](samples/plan-example.csv),
[`samples/plan-example.json`](samples/plan-example.json).
Кнопка **Шаблон** в приложении скачивает такой же пример CSV.

> Загрузка ничего не сохраняет сразу: план показывается в конструкторе,
> его можно поправить, а затем **принять** (сохранить в текущий план либо
> создать новый) или **отклонить**.

---

## CSV — для подготовки в Excel / Google Sheets

Одна строка = одна неделя, колонки = дни недели.

```csv
Нед,Начало,Конец,Акцент,Тип,Пн,Вт,Ср,Чт,Пт,Сб,Вс
1,10.05,16.05,Развитие,dev,6–8 км легко,,3×7 мин по 4:35,,8–10 км средний,8 км по 5:05,12 км легко
2,17.05,23.05,Развитие,dev,7–8 км легко,,6×1 км по 4:30,,10 км средний,4×2 км по 4:48,14–16 км легко
```

### Колонки

| Значение | Допустимые заголовки (регистр не важен) | Обязательна |
|---|---|---|
| Номер недели | `Нед`, `Неделя`, `№`, `W`, `Week` | нет — нумеруется по порядку строк |
| Дата начала | `Начало`, `Старт`, `Start` | нет |
| Дата конца | `Конец`, `Окончание`, `End` | нет |
| Акцент недели | `Акцент`, `Фокус`, `Accent`, `Focus` | нет |
| Тип недели | `Тип`, `Type`, `Фаза`, `Phase` | нет — по умолчанию «Развитие» |
| Понедельник | `Пн`, `Понедельник`, `Mon`, `Monday` | нет |
| Вторник | `Вт`, `Вторник`, `Tue`, `Tuesday` | нет |
| Среда | `Ср`, `Среда`, `Wed`, `Wednesday` | нет |
| Четверг | `Чт`, `Четверг`, `Thu`, `Thursday` | нет |
| Пятница | `Пт`, `Пятница`, `Fri`, `Friday` | нет |
| Суббота | `Сб`, `Суббота`, `Sat`, `Saturday` | нет |
| Воскресенье | `Вс`, `Воскресенье`, `Sun`, `Sunday` | нет |

### Правила

- Первая непустая строка — **заголовок**; он обязателен.
- Нужна хотя бы одна колонка дня недели, иначе файл отклоняется.
- Неизвестные колонки игнорируются и перечисляются в предупреждениях.
- Отсутствующие дни считаются пустыми (день отдыха).
- Пустые строки пропускаются. Нужна минимум одна строка данных.
- Если текст содержит запятую, перенос строки или кавычку — оберните ячейку
  в двойные кавычки: `"3×7 мин, пауза 3:00"`. Кавычка внутри удваивается (`""`).
- Кодировка — **UTF-8**. Экспорт добавляет BOM, чтобы Excel корректно открывал
  русский текст; при загрузке BOM игнорируется.

### Тип недели

Принимается и код, и русская подпись:

| Код | Подпись | Цвет бейджа |
|---|---|---|
| `dev` | `Развитие` | синий |
| `peak` | `Пик` | зелёный |
| `taper` | `Тейпер` | жёлтый |
| `load` | `Разгрузка` | бирюзовый |
| `race` | `Старт` | красный |

Неизвестное значение → `dev` («Развитие») с предупреждением.

## JSON — точная структура, вместе с данными гонки

```json
{
  "format": "running-tracker-plan",
  "version": 1,
  "race": {
    "race_name": "Московский полумарафон",
    "race_date": "2026-08-09",
    "target_time": "1:40",
    "plan_start": "2026-05-10"
  },
  "weeks": [
    { "w": 1, "start": "10.05", "end": "16.05", "accent": "Развитие", "type": "dev",
      "mon": "6–8 км легко", "tue": "", "wed": "3×7 мин", "thu": "",
      "fri": "8–10 км средний", "sat": "8 км по 5:05", "sun": "12 км легко" }
  ]
}
```

### Поля

| Поле | Тип | Описание |
|---|---|---|
| `format` | строка | необязательно, `running-tracker-plan` |
| `version` | число | необязательно; при версии выше поддерживаемой — предупреждение |
| `race` | объект | необязательно; используется **только** при создании нового плана из файла |
| `race.race_name` | строка | название гонки |
| `race.race_date` | строка | дата старта, `ГГГГ-ММ-ДД` |
| `race.target_time` | строка | целевое время, например `1:40` |
| `race.plan_start` | строка | дата начала плана, `ГГГГ-ММ-ДД` — от неё считается «неделя N» |
| `weeks` | массив | недели плана (обязательно, непустой) |
| `weeks[].w` | число | номер недели; при загрузке перенумеровывается по порядку |
| `weeks[].start` / `end` | строка | даты недели в свободном виде (`10.05`) |
| `weeks[].accent` | строка | акцент недели |
| `weeks[].type` | строка | см. таблицу типов выше |
| `weeks[].mon` … `sun` | строка | тренировки по дням; пустая строка = отдых |

Допускается «голый» массив недель без обёртки:

```json
[ { "w": 1, "mon": "8 км легко", "sun": "12 км легко" } ]
```

## Что происходит после загрузки

1. Файл разбирается и проверяется.
   - **Ошибки** (не распознан формат, нет строк данных, нет колонок дней) —
     показывается список, текущий план **не меняется**.
   - **Предупреждения** (неизвестные колонки, неизвестный тип) — показываются,
     загрузка продолжается.
2. План открывается **в конструкторе** — любую ячейку можно поправить.
3. Дальше три варианта:
   - **Сохранить в текущий план** — записывается новая версия активного плана
     (предыдущая остаётся в истории);
   - **Создать новый план** — заводится отдельный план (данные гонки берутся
     из `race`, если файл в JSON), текущий не затрагивается;
   - **Отменить импорт** — возврат к прежнему плану, ничего не сохраняется.

---

## Round-trip: выгрузить → поправить → загрузить

1. **⤓ CSV** — скачать текущий план.
2. Открыть в Excel / Google Sheets, поправить, сохранить как CSV (UTF-8).
3. **⤒ Загрузить** — выбрать файл, проверить предпросмотр, сохранить.

Экспорт в **JSON** дополнительно сохраняет данные гонки, поэтому подходит
как резервная копия плана целиком.
