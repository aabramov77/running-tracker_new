# #58 — Новая инструкция ИИ-тренера

- Issue: https://github.com/aabramov77/running-tracker_new/issues/58
- Ветка: `Dev`
- Коммиты: `feat: #58 …`

## Контекст

Роль и правила ИИ-тренера (`COACH_CHAT_SYSTEM_PROMPT`, #46) были короткими:
опираться на данные, не додумывать, учитывать профиль, «не врач», разбор
тренировки одним пунктом и «3–8 предложений». У спортсмена есть инструкция,
по которой работает тренер-человек: стиль без мотивационной воды, подход через
периодизацию, правила корректировки и ответ по разделам. Её нужно перенести в
промпт, адаптировав к тому, что приложение реально передаёт модели.

## Решения

| Вопрос | Решение |
|---|---|
| Личные данные и старты из инструкции | В промпт не идут: инструкция общая для всех спортсменов. Профиль, цель и план приходят блоком данных (`coach_chat_data`) |
| Специализация «10 км и полумарафон» | Нет. Роль — тренер на длинные дистанции, дистанцию и уровень модель берёт из цели и профиля |
| Ответ по разделам | Только для разбора тренировки и корректировки плана, пустые разделы пропускаются. На простой вопрос — коротко, 3–8 предложений. «Что видно по данным» — выводы, а не пересказ цифр |
| Показатели Garmin | Перечислены только те, что собирает `build_llm_context`: темп, пульс, каденс, набор, круги, дрейф, зоны, ощущения, заметки. HRV, training effect, recovery time, readiness — только если спортсмен написал о них сам, требовать их нельзя |
| Жара, ветер, недосып, стресс | По заметкам спортсмена, рельеф — по набору высоты. Если тренировка хуже ожидаемого без видимой причины — спросить |
| «Сначала уточни» перед планом | Объём, дни, рекорды, цель, ограничения уже есть в данных — спрашивать только недостающее (силовые, другие виды нагрузки) |
| «Составь план» | План целиком в чате не меняется: правки только в окне недель (`AI_PLAN_WINDOW_WEEKS`) и только через формат ответа. Если окна нет, формат правок не показан — модель понимает, что предлагать их нельзя |
| Длина ответа | Лимит вывода OpenAI/DeepSeek — `LLM_MAX_TOKENS` = 8000, разбор по разделам вместе с правками в него помещается |

## Изменения

### Промпт — `llm_prompt.py`

- `COACH_CHAT_SYSTEM_PROMPT` переписан: роль, «Стиль», «Подход», «Правила»,
  «Разбор тренировки», «Просьба составить план», «Как писать».
- Сохранено из прежнего: не додумывать цифры, не выдавать оценки за измерения,
  не ставить тренировки в недоступные дни, «не врач», не пересказывать данные.
  Фраза «беговой тренер» осталась — на неё смотрит `test_routes`.
- `COACH_CHAT_REPLY_FORMAT`, `COACH_CHAT_PROPOSAL_FORMAT` и блок данных не
  менялись.
- Инструкция стала длиннее: ~3200 символов против ~1100, это около +700
  токенов на каждый ход диалога.

### Тесты — `tests/test_ai_coach.py`

- `test_instructions_carry_the_coaching_rules_with_either_format` — ключевые
  правила есть в инструкции и с форматом правок, и без него.

## Верификация

1. `python -m pytest` зелёный.
2. Dev-стенд: разбор тренировки с FIT — ответ по разделам, без пустых; простой
   вопрос — коротко, без разделов; просьба составить план — не переспрашивает
   объём и дни из профиля, правки только в окне недель.
