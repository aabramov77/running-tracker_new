## Контекст

Issue создан коротким «Сделать help для пользователя». Приложение
разрослось: несколько планов и составление плана с ИИ, план/факт, пробежки
вне планов, нагрузка по темпу и пульсу с ценой работы, импорт FIT/CSV,
ИИ-тренер с памятью, тренер с диалогом, погода, профиль по блокам, роли.
После входа пользователь попадает сразу в «План» — без подсказок, с чего
начать, и без расшифровки терминов. README подробный, но он для
разработчика и из приложения недоступен; стартовая страница видна только до
входа.

## Решение

Встроенная справка — статическая вкладка `#tab-help` в `index.html`:
оглавление и 11 разделов («Как начать», «Планы», «Пробежки и старты»,
«Нагрузка», «ИИ-тренер», «Тренер», «Погода», «Профиль», «Доступ и данные»,
«Частые вопросы», «Для администратора»). Кнопки «ⓘ» у терминов открывают
её на нужном подзаголовке, «‹ Назад» возвращает на вкладку, откуда пришли.
Бэкенд, API и GCS не меняются: справка — не бизнес-данные.

## Решения, согласованные с пользователем (2026-11-16)

## История решений

- Черновик 2026-11-08 писался до перехода на OpenSpec и до #87, #71, #69:
  в справку добавлены профиль по блокам, область «Без плана» и составление
  плана с ИИ.
- «Для тренера» скрыт новым гейтом `coach-self` (`currentIsCoach`):
  существующий `coach` включён и у спортсмена, у которого есть тренер.
- «План устарел» показывается системным `alert` — кнопку туда не
  поставить. Вместо «ⓘ» последняя фраза сообщения: «Подробнее — в
  «❓ Справке», раздел «Планы».» (`PLAN_STALE_HELP`). Добавлено во все
  сообщения об отказе по `plan_stale`, включая тренерские
  (`COACH_STALE_TEXT`, `COACH_STALE_LOST_TEXT`, лист дня).
- «‹ Назад» — сверх черновика: справка, открытая «ⓘ» с экрана тренера или
  профиля, иначе теряла бы место, откуда пришли.
- «ⓘ» добавлена и в карточку «Нагрузка за 7 дней» на «Сегодня»; клик не
  уводит в «Аналитику» (`stopPropagation`).
- Переходы по оглавлению — `showHelp()`, без смены `location.hash`:
  маршрутизации по хэшу в приложении нет.
- В README («Процесс») — правило: фича, меняющая видимое поведение, правит
  раздел справки.
- 2026-11-16, после проверки на dev-стенде (`app.js?v=60`): «не хватает
  кнопки возврата обратно к меню и приходится скролить наверх». Добавлены
  закреплённые кнопки справа внизу — «↑ Оглавление» и, если справку открыли
  «ⓘ», «‹ Назад»; видны, только пока карточка оглавления за верхом экрана,
  на телефоне — над нижней панелью. Отвергнуты ссылка «↑ К оглавлению» в
  конце каждого раздела (не помогает посреди длинного раздела и не
  возвращает «Назад») и липкое оглавление (пол-экрана на телефоне).

## Верификация

- `pytest` — 1672 passed; из них `tests/test_frontend_sanity.py` — 145.
- jsdom с настоящими `index.html` и `app.js`, заглушки `fetch`, `alert`,
  `Chart` (37 проверок, все прошли):
  - меню: «Справка» последняя; из меню «‹ Назад» нет; оглавление
    прокручивает к разделу, `location.hash` не меняется;
  - роли: `user` — нет «Для тренера» и «Для администратора» (ни в тексте,
    ни в оглавлении); спортсмен с тренером — «Тренер» виден, «Для
    тренера» нет; тренер — виден; админ — «Для администратора» виден;
    скрытый якорь прокручивает к началу;
  - «ⓘ»: три у плиток «Аналитики» (и в варианте «—» цены работы), блоки
    профиля, память тренера, «Нагрузка за 7 дней» на «Сегодня» — каждая
    открывает свой подзаголовок; клик не раскрывает блок профиля и не
    сворачивает память; «‹ Назад» возвращает на «Аналитику», «Профиль»,
    «Сегодня»; оглавление «Назад» не сбрасывает;
  - телефон: «Ещё» → «❓ Справка», группа `more` (возврат «‹ Ещё»);
  - справка не обращается к API (`fetch` бросает — вызовов 0);
  - сохранение конструктора с ответом 409 — сообщение заканчивается
    ссылкой на раздел «Планы».
- Закреплённые кнопки — jsdom, десктоп и телефон (ещё 24 проверки, итого
  61, все прошли): из меню блока нет; после перехода к «Частым вопросам» —
  есть, без «‹ Назад»; «↑ Оглавление» прокручивает к началу и прячет блок;
  событие `scroll` ниже оглавления показывает блок, у оглавления — прячет;
  после «ⓘ» в блоке есть «‹ Назад», она возвращает в «Профиль»; на
  другой вкладке блок не виден; снова из меню — «‹ Назад» в блоке скрыта.
  Положение карточки оглавления в jsdom — заглушка `getBoundingClientRect`.
- Раскладка — headless Edge, копия `index.html` без скриптов: на 375 px
  нет горизонтальной прокрутки и вылезающих элементов, оглавление в одну
  колонку, «‹ Ещё» виден, «ⓘ» 20×20; на десктопе оглавление в 5 колонок.
  Закреплённые кнопки при прокрутке до самого низа: телефон — 699–739 px
  при верхе нижней панели 750, конец последнего раздела — 667; десктоп —
  751–791, конец раздела — 691: ничего не перекрыто.
- Тексты: названия кнопок и вкладок, упомянутые в справке, сверены с
  `index.html` и `app.js` поиском; пошагово сценарии в браузере не
  проходились. Тёмная тема — цвета только через токены, визуально не
  смотрелась.
- Dev-стенд, `app.js?v=60` (2026-11-16): пользователь проверил вручную —
  работает; замечание про возврат к оглавлению — см. «История решений».
