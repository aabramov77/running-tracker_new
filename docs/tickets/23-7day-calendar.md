## Контекст

Тренировочный план показывал 5 дней недели: Вс, Пн, Ср, Пт, Сб (поля
`sun/mon/wed/fri/sat` в каждой неделе). Вторник и четверг отсутствовали.
Переводим календарь на все **7 дней** (добавляем `tue` и `thu`) в привычном
порядке **Пн Вт Ср Чт Пт Сб Вс** (`mon tue wed thu fri sat sun`).

## Миграция существующих планов — ленивая (без разрушающей перезаписи)

Планы версионируются per-user в GCS (`users/{sub}/plan/...`) по политике
append-only из `CLAUDE.md`, поэтому массовая перезапись нежелательна:

- **Рендер толерантен к отсутствию поля** — старый план без `tue`/`thu`
  показывается в 7-дневной сетке с пустыми Вт/Чт.
- **Апгрейд при первом сохранении** — как только пользователь войдёт в
  конструктор и нажмёт «Сохранить», новая версия плана запишется со всеми
  7 полями. Это и есть миграция: через обычный версионный save, без
  отдельного endpoint и без переписывания чужих данных.

Серверный migration-скрипт не требуется: `POST /plan` уже принимает
произвольный `weeks`.

## Изменения

### `index.html`
- `<thead>` таблицы плана → 7 колонок в порядке Пн Вт Ср Чт Пт Сб Вс.
  Всего столбцов: 3 + 7 = **10**.
- Cache-buster `app.js?v=18`.

### `app.js`
- Константа порядка дней — единый источник истины:
  ```js
  const PLAN_DAYS = [['mon','Пн'],['tue','Вт'],['wed','Ср'],['thu','Чт'],['fri','Пт'],['sat','Сб'],['sun','Вс']];
  const PLAN_COLSPAN = 3 + PLAN_DAYS.length;  // 10
  ```
- `renderPlan()` — 7 day-ячеек по `PLAN_DAYS` и в обычном виде, и в
  конструкторе; `colspan` пустого состояния и строки «+ Неделя» → 10.
- `addPlanWeek()` — новая неделя со всеми 7 днями пустыми.
- `collectPlanEdits()` — **без изменений**, он generic по `data-field`
  и подхватывает `tue`/`thu` автоматически.

### `main.py`
- `format_context_for_llm()` — передаёт LLM все 7 дней через новый
  `_week_days_str()`; пустые/отсутствующие дни пропускаются
  (совместимость со старыми 5-дневными планами).
- `INITIAL_PLAN` не трогаем — исторические данные, для новых пользователей
  не используется.

### `tests/test_main.py`
- Вт/Чт в контексте LLM; `_week_days_str` пропускает пустые дни и не падает
  на legacy-неделе.
