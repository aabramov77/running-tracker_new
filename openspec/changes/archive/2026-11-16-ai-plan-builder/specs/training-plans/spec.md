# Spec Delta

## MODIFIED Requirements

### Requirement: Реестр планов
`GET /plans` SHALL отдавать `{"active_plan_id", "plans": [...]}` — все планы пользователя, включая архивные. Карточка плана MUST содержать `id`, `created_at`, `archived`, `race_name`, `race_date`, `target_time`, `plan_start`. У плана, созданного тренером, в карточке ещё роль и идентификатор создателя. У плана, созданного из черновика ИИ, — роль `ai`, идентификатор спортсмена и `ai_source` с id разбора и реплики черновика.

#### Scenario: Пользователь без планов
- **WHEN** новый пользователь вызывает `GET /plans`
- **THEN** ответ `{"active_plan_id": null, "plans": []}`

#### Scenario: План из черновика ИИ
- **WHEN** спортсмен создал план из черновика ИИ-тренера
- **THEN** карточка плана в `GET /plans` содержит `created_by_role: "ai"` и `ai_source` с разбором и репликой

### Requirement: Календарь плана
Вкладка «План» SHALL показывать недели строками с семью днями Пн–Вс, датами, акцентом и бейджем типа недели (`dev` «Развитие», `peak` «Пик», `taper` «Тейпер», `load` «Разгрузка», `race` «Старт»). Текущая неделя MUST подсвечиваться. В переключателе планов план, созданный тренером, MUST быть подписан «от тренера», а созданный из черновика ИИ — «от ИИ».

#### Scenario: Открытие вкладки
- **WHEN** спортсмен открывает «План» в середине подготовки
- **THEN** строка текущей недели выделена

#### Scenario: План от ИИ в переключателе
- **WHEN** у спортсмена есть план, созданный из черновика ИИ-тренера
- **THEN** в переключателе планов он подписан «от ИИ»
