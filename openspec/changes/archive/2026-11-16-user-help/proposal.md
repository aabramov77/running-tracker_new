# Proposal

## Why

Приложение разрослось (issue #64): несколько планов и составление плана с
ИИ, план/факт, пробежки вне планов, нагрузка по темпу и по пульсу с ценой
работы, импорт FIT/CSV, ИИ-тренер с памятью, тренер с диалогом, погода,
профиль по блокам, роли. После входа пользователь попадает сразу в «План»:
в интерфейсе нет ни рассказа, с чего начать, ни расшифровки терминов
(rTSS, TRIMP, цена работы, пороговый темп, пульсовые зоны). Подробное
описание есть только в README — он для разработчика и из приложения
недоступен; стартовая страница видна только до входа.

## What Changes

- Новая вкладка «❓ Справка»: оглавление-ссылки вверху и линейные разделы —
  «Как начать», «Планы», «Пробежки и старты», «Нагрузка», «ИИ-тренер»,
  «Тренер», «Погода», «Профиль», «Доступ и данные», «Частые вопросы»,
  «Для администратора». Текст сухой, как в README, с обращением на «вы».
- В справку попадает и недавнее: составление плана с ИИ (#69), пробежки
  вне планов и область «Без плана» (#71), профиль по блокам (#87).
- Вход в справку: на широком экране — кнопка «❓ Справка» последней в меню
  вкладок; на телефоне — пункт «❓ Справка» в «Ещё».
- Подраздел «Для тренера» виден только тренеру, раздел «Для
  администратора» — только администратору; скрытие по роли — тем же
  механизмом, что у пунктов «Тренер» и «Пользователи».
- Кнопки «ⓘ» у терминов (первая волна): нагрузка по темпу (rTSS), по
  пульсу (TRIMP), цена работы, блоки профиля «Порог и МПК» и «Пульс и
  зоны», «Что помнит тренер». Нажатие открывает справку на нужном месте;
  в справке есть «‹ Назад» — возврат туда, откуда пришли.
- «План устарел» показывается системным `alert`, кнопку в него не
  поставить: в конце этого сообщения появляется ссылка-подсказка текстом
  «Подробнее — в «❓ Справке», раздел «Планы».».
- Справка — статика в `index.html` и `style.css`; бэкенд, API и хранилище
  не меняются.
- Не входит: онбординг-баннер и тур при первом входе, поиск по справке,
  скриншоты и видео, справка в GCS с версиями, «Что нового» (issue #30),
  справка на стартовой странице до входа.

## Capabilities

### New Capabilities

- `user-help`: встроенная справка — вкладка, её разделы и оглавление,
  вход с десктопа и с телефона, скрытие разделов по роли, контекстные
  кнопки «ⓘ» и возврат к месту, откуда открыли справку.

### Modified Capabilities

- `mobile-layout`: в требовании «Нижняя панель» в «Ещё» добавляется пункт
  «Справка».

## Impact

- Фронтенд: `index.html` (вкладка `#tab-help`, кнопка в `.nav`, пункт в
  `#tab-more`, `?v=` у `app.js` и `style.css`), `app.js` (`showHelp`,
  возврат, `TAB_GROUP`, гейтинг подраздела тренера, кнопки «ⓘ» в
  отрисовке нагрузки и памяти тренера, текст `PLAN_STALE_TEXT`),
  `style.css` (оглавление, разделы, кнопка «ⓘ»).
- Тесты: `tests/test_frontend_sanity.py` — проверки связности справки.
- Документация: `README.md` — строка о справке; `docs/tickets/64-user-help.md`
  — план под новое решение.
- Бэкенд, API, GCS — без изменений.
