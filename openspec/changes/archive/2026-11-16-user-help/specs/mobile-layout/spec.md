# Spec Delta

## MODIFIED Requirements

### Requirement: Нижняя панель
Вместо меню вкладок SHALL быть нижняя панель: «Сегодня», «План», «+», «Прогресс», «Ещё». «Прогресс» MUST объединять журнал и аналитику, «Ещё» — ИИ-тренера, старты, профиль, а также «Тренер» и «Пользователи» для тех, кому они положены, и «Справку»; счётчик непрочитанных от тренера показывается и на «Ещё».

#### Scenario: Открыть старты на телефоне
- **WHEN** пользователь на телефоне нажимает «Ещё»
- **THEN** видит пункты «ИИ-тренер», «Старты», «Профиль»

#### Scenario: Справка на телефоне
- **WHEN** пользователь на телефоне нажимает «Ещё»
- **THEN** среди пунктов есть «❓ Справка»
