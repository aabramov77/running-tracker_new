# Spec Delta

## ADDED Requirements

### Requirement: Настройки модели в режиме просмотра
У администратора настройки модели в «Профиле» SHALL быть блоком с режимом просмотра: провайдер, модель, глубина рассуждения и маска ключа текстом либо «не настроено». Форма с кнопками «Сохранить» и «Отмена» MUST раскрываться только по «Изменить»; «Отмена» очищает введённый ключ и не создаёт версию.

#### Scenario: Модель настроена
- **WHEN** администратор с сохранённым конфигом открывает «Профиль»
- **THEN** блок показывает провайдера, модель, глубину и маску ключа текстом, полей формы на экране нет

#### Scenario: Модель не настроена
- **WHEN** администратор открывает «Профиль», а конфиг ещё не записан
- **THEN** блок показывает «не настроено» и кнопку «Изменить»

### Requirement: Ключ при сохранении настроек модели
Форма настроек модели SHALL пояснять, что ключ нужно вводить при каждом сохранении. Сохранение без ключа MUST оставлять блок открытым с ошибкой под полем ключа и не создавать версию; после успешного сохранения поле ключа очищается, а блок возвращается в просмотр с новыми значениями.

#### Scenario: Сохранение без ключа
- **WHEN** администратор меняет модель, оставляет поле ключа пустым и нажимает «Сохранить»
- **THEN** под полем ключа ошибка «Введите API-ключ», блок открыт, версия конфига не создана

#### Scenario: Смена модели
- **WHEN** администратор меняет модель, вводит ключ и сохраняет
- **THEN** блок в просмотре показывает новую модель и маску ключа, поле ключа пустое

### Requirement: Проверка сохранённого ключа из просмотра
Кнопка «Проверить ключ» SHALL быть в режиме просмотра блока и проверять сохранённый конфиг. Пока конфиг не записан, кнопка MUST быть недоступна; в открытой форме кнопки нет, чтобы её не принимали за проверку введённого ключа.

#### Scenario: Проверка без конфига
- **WHEN** администратор открывает блок с ненастроенной моделью
- **THEN** кнопка «Проверить ключ» недоступна

#### Scenario: Форма открыта
- **WHEN** администратор нажал «Изменить»
- **THEN** в блоке нет кнопки «Проверить ключ», только «Сохранить» и «Отмена»
