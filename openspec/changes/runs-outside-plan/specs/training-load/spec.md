# Spec Delta

## MODIFIED Requirements

### Requirement: Сводка и графики аналитики
Вкладка аналитики SHALL показывать число пробежек, сумму километров, лучший темп, неделю плана «N из M» с процентом пройденного, обратный отсчёт до даты гонки, график недельного объёма план/факт и график темпа по датам пробежек. Плановые столбцы недель с неточным объёмом MUST быть бледнее и подписаны «план не меньше N км»; в областях «все» и «без плана» плановых столбцов нет.

#### Scenario: Неточная неделя на графике
- **WHEN** у недели плановый объём неточный
- **THEN** её плановый столбец бледнее, подсказка «план не меньше N км»

#### Scenario: Аналитика пробежек без плана
- **WHEN** спортсмен выбирает в аналитике область «Без плана»
- **THEN** число пробежек, километры, лучший темп и график темпа считаются только по нескрытым пробежкам с `plan_id: null`
- **AND** на графике недельного объёма нет плановых столбцов
